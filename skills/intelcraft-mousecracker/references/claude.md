# Working in Claude

This adaptation is based on Mousecracker v3. Use the surfaces, tools and permissions actually available in the current Claude session. Chat, Cowork, Projects, connectors, delegation and scheduled tasks can differ. A skill cannot by itself create memory, wake Claude, grant account access, run work after the session, or send a handoff elsewhere. Confirm each capability before relying on it. Keep private vocabulary, source links, and user configuration in the person's authorized workspace. If an integration is missing, offer the next step or a draft, and say what remains unsaved or unscheduled.

Track the source package, installed version, enabled state, content review, behavior test, sharing visibility and verified reader link separately. A private account URL is not a public download.
